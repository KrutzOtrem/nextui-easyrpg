# RPG Maker 2000/2003 Core

This core emulates RPG Maker 2000, 2003 and EasyRPG games.

## BIOS Files

It is not always necessary, but install RTPs and copy them in your `BIOS/EASYRPG/rtp` folder:

- Extracted `RTP2000` files inside `BIOS/EASYRPG/rtp/2000`
- Extracted `RTP2003` files inside `BIOS/EASYRPG/rtp/2003`

## ROM Files

Put those in your `Roms/<folder name> (EASYRPG)` folder.
